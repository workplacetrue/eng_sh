# English Life Agent — локальный MVP

Практика английского через жизненные ситуации на **MacBook Air M1, 8 ГБ RAM**.
Ollama + **Qwen3 4B Q4_K_M**, SQLite, локальный CLI. Ключи OpenAI, Telegram,
PostgreSQL, Docker и платные сервисы не нужны. После установки и загрузки моделей
текстовый режим работает без Интернета.

## Установка и запуск на Mac

Нужны Apple Silicon macOS, около 5 ГБ свободного диска для модели и окружения,
[Homebrew](https://brew.sh). Из папки репозитория:

```sh
./scripts/install-macos.sh
./start.sh
```

Установщик устанавливает uv и Ollama через Homebrew, Python 3.12, зависимости из
`uv.lock`, запускает Ollama как локальную службу и загружает `qwen3:4b-q4_K_M`.
Повторный запуск безопасен: данные и `.env` не перезаписываются. Установка требует
Интернета; обычный `./start.sh` не запускает загрузку пакетов.

Проверка модели: `./start.sh doctor`. Дополнительные настройки можно положить
в `.env` по образцу `.env.example`. По умолчанию ничего заполнять не нужно.
Ollama слушает loopback; не публикуйте её порт наружу.

## Как заниматься

```text
/start             регистрация и короткая диагностика (ориентир A2)
/lesson 5          одно практическое задание
/lesson 10         повторение, диалог, обратная связь
/lesson 30         связанные ситуации, усложнение, самостоятельные ответы
/resume            продолжить или показать последний вопрос
/progress          шесть навыков и изменения
/repeat            активное припоминание выражений, срок которых наступил
/weekly            отчёт за последние семь дней
/pause             остановить таймер и сохранить занятие
/finish            завершить и сохранить оценку
/delete_me         удалить учебные данные после подтверждения DELETE
/help              команды
quit               выйти (активное занятие ставится на паузу)
```

Таймер работает даже пока вы не вводите текст. По истечении времени начинается
подведение итогов; сама генерация на M1 может занять дополнительное время.
При ошибке генерации состояние не теряется, автоматическое завершение ставится
на паузу, чтобы не запускать бесконечные повторы. `/resume`, затем `/finish`
повторяют попытку. После аварийного выхода незавершённый диалог остаётся в БД.
При запуске через несколько дней просроченное занятие будет завершено, либо его
можно закончить вручную. Еженедельный отчёт предлагается при следующем запуске:
приложение не работает фоновым сервером.

## Память и методика

БД создаётся автоматически: `~/.english-life/progress.db`, независимо от текущей
папки. Она хранит профиль, результаты, активные выражения, грамматические ошибки,
повторы и снимки навыков. Доступ к файлу ограничен владельцем. Один CLI-процесс
на БД защищён файловой блокировкой. Для отдельного тестового профиля задайте
`DATABASE_URL=sqlite+aiosqlite:////absolute/path/test.db`.

Сохраняется ограниченный контекст незавершённых занятий; после завершения реплики
очищаются, остаются структурированные результаты. Удаление `/delete_me` каскадно
удаляет учебные данные, включая незавершённые занятия. Локальные резервные копии
(Time Machine и т. п.) управляются пользователем отдельно.

Шесть независимых показателей: reading, listening, speaking independence,
grammar in speech, active vocabulary, functional communication. 0–100 показывает
наблюдаемое выполнение конкретных задач следующего уровня, **не официальный CEFR**.
Без голосовых данных speaking/listening остаются без оценки. Текстовая диагностика
проверяет чтение, самостоятельное письменное выражение и функциональное общение.
Произношение по транскрипции не оценивается.

Сценарии: аэропорт, такси, кафе, аренда, знакомства, мнения, работа; сложность
адаптируется по ответам, подсказки сокращаются. Предыдущие ошибки передаются
следующему занятию. Интервалы повторений: 1, 2, 4, 7, 14, 30, 60 дней.
Каждый седьмой урок получает контрольную переоценку. Педагогическое качество
оценок маленькой модели нужно проверять на реальных занятиях.

## Настройки для 8 ГБ RAM

По умолчанию `CONTEXT_SIZE=4096`, `MAX_OUTPUT_TOKENS=1000`, `HISTORY_CHARS=1800`,
thinking выключен, удержание модели в Ollama — 2 минуты. Вес Q4-модели около
2.5 ГБ, **общая RAM выше** из-за macOS, KV cache и runtime. Закройте тяжёлые
приложения и смотрите Memory Pressure. Производительность на M1 в этой Linux-среде
не измерялась. Установка модели не гарантирует отсутствие swap на вашем Mac.

`MODEL` меняет локальную модель без изменения учебной логики. Адаптер реализует
`respond(context, history, message) -> Turn`; новый API/LLM подключается через
`create_backend`. Ошибочный JSON или оборванная генерация не записывают прогресс.
Повторной скрытой генерации нет. Ollama-запросы идут только на loopback и игнорируют
переменные внешнего proxy. Логирование диалогов и tracing отсутствуют.

## Необязательная локальная речь

Текстовый режим не требует голосовых пакетов. После его проверки:

```sh
brew install whisper-cpp portaudio
uv sync --frozen --extra voice
```

Нужен локальный файл **ggml-tiny.en.bin** из официального проекта whisper.cpp
(репозиторий `ggml-org/whisper.cpp`, инструкция `models/README.md`; загрузите модель
`tiny.en` по их инструкции). Укажите путь в `.env`:

```dotenv
WHISPER_MODEL=/Users/your-name/.english-life/models/ggml-tiny.en.bin
WHISPER_BINARY=whisper-cli
```

`/record 10` записывает 10 секунд микрофона и отправляет локальную транскрипцию
репетитору. macOS может запросить разрешение Terminal на микрофон. Максимум 30 секунд,
4 потока Whisper, файл WAV и транскрипция удаляются после обработки. Сначала запись,
потом STT, потом LLM: тяжёлые вычисления выполняются последовательно. Модель Whisper
загружается отдельным процессом и освобождается после распознавания.

`/voice` включает системный macOS `say`, `/text` возвращает текст. Используется
системный голос по умолчанию: для смешанного русского/английского текста настройте
подходящий голос в macOS. `/listen` во время диагностики воспроизводит короткую
английскую реплику без показа её текста, затем задаёт вопрос. Голосовой адаптер
заменяемый; он не требует облачного STT/TTS. Аудиокачество, разрешения и расход RAM
необходимо проверить на самом Mac. Не устанавливайте большие Whisper/TTS-модели
на 8 ГБ до проверки памяти.

## Разработка и тесты без модели

```sh
uv sync --frozen --extra dev
uv run pytest -q
uv run ruff check english_life tests
DATABASE_URL=sqlite+aiosqlite:////tmp/english-life-demo.db ./start.sh demo --smoke
./start.sh demo
```

Demo честно помечен и не оценивает английский; это проверка памяти и управления
занятиями. Автотесты адаптера используют mock HTTP, а не живую Ollama.
Схема v1 автоматически создаётся через SQLAlchemy; сохранены Alembic-миграции
для будущих изменений (`uv run alembic upgrade head` из корня). Перед обновлениями
схемы делайте резервную копию БД при закрытом приложении.

Структура: `agents/` — сменные LLM-адаптеры и инструкции четырёх модулей;
`learning/` — цикл и планирование; `memory/` + `tools/` — проверяемые транзакции;
`voice/` — локальная речь; `tests/` — автоматические проверки.
Адаптеры первоначальной версии Telegram/OpenAI сохранены как необязательный
`legacy` extra, но не используются локальным CLI и не требуют установки.
Серверная инфраструктура удалена. [Актуальный план](docs/IMPLEMENTATION_PLAN.md).
