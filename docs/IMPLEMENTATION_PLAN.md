# Локальная архитектура (актуальное ТЗ)

Цель: MacBook Air M1, 8 ГБ RAM, без обязательных внешних API.

## Результат анализа готового кода

Сохранены SQLAlchemy-модели, SQLite-совместимая схема и Alembic,
сервис занятий, схема структурированных результатов, планировщик повторов,
запись результатов с валидацией, снимки прогресса и тесты памяти.

Изменены основной LLM-адаптер, интерфейс, настройки и зависимости.
OpenAI Agents SDK и Telegram-адаптеры сохранены как необязательный legacy extra,
не импортируются обычным CLI. PostgreSQL больше не требуется.
Docker/Railway удалены по новому ТЗ. CI проверяет SQLite без сервисов.

## План и проверки

1. **Память и учебный цикл:** SQLite создаётся автоматически в ~/.english-life;
   транзакции, возобновление после рестарта, диагностика, длительности, повторения,
   изоляция данных, удаление. Проверка: тесты + повторный запуск demo на одной БД.
2. **Ollama:** единый контракт respond(context, history, message) -> Turn;
   Qwen3 4B Q4_K_M, think=false, контекст 4096, короткая история, structured JSON.
   Проверка: HTTP-контракт, валидация, ошибки сети, некорректные ответы,
   отсутствие внешнего прокси. Живой model smoke нужен на целевом Mac.
3. **CLI:** команды, истечение времени без нового ввода, пауза/продолжение,
   один процесс на файл БД; недельный отчёт при следующем запуске.
   Проверка: smoke и тесты CLI, без подмены реального LLM демо-оценками.
4. **macOS:** установщик Homebrew/uv/Ollama, загрузка квантованной модели,
   запуск ./start.sh. Проверка shell syntax в cloud; полная установка на M1 отдельно.
5. **Голос после текста:** необязательная запись 1–30 сек; whisper.cpp tiny.en,
   системный say вместо второго большого TTS. Аудио временно, сразу удаляется.
   Проверка адаптеров с mock; затем микрофон, разрешения macOS и RAM на Mac.

## Приёмка на Mac

Установка, doctor, реальная диагностика; уроки 5/10/30; завершение,
/progress, перезапуск и /resume, ошибки следующего урока, /repeat,
недельный отчёт и /delete_me. В Activity Monitor проверить Memory Pressure
при одновременных Qwen и tiny.en. Если давление растёт — закрыть тяжёлые
приложения и уменьшить CONTEXT_SIZE; не обещать, что вес модели равен всей RAM.
Полностью офлайн после однократной загрузки зависимостей и моделей.
